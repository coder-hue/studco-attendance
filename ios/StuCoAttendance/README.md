# StuCo Attendance for iPhone

One private app for creating and running Student Council attendance events.

## Attendance

- Existing attendance admin sign-in
- Create named attendance events with backup check-in windows
- Display full-screen event QR codes directly on the iPhone
- Live present, missing, and member totals
- Live roster with check-in times
- Manually open or close attendance, or use its backup schedule
- Edit, delete, archive, and finalize attendance events
- Lock Screen and Dynamic Island Live Activity

## Run

1. Upload `public/mobile-admin-api.php` from the attendance project to `attendance.coderhue.dev`.
2. Open `StuCoAdmin.xcodeproj`.
3. Select your Apple Development Team for `StuCoAdmin` and `StuCoAdminWidgets`.
4. Run on your iPhone and unlock with Face ID.

The bundle identifiers are `dev.coderhue.stucoadmin` and `dev.coderhue.stucoadmin.widgets`.
